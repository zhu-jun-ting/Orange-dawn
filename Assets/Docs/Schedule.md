# Orange-dawn Progress – Last Week

**Card & Board System:**
- Refactored card logic, made CardMaster a MonoBehaviour, cleaned up old holders.
- Improved link visuals and drag/placement feedback.
- Made card value updates event-driven and more reliable.
- Board and hand now update cards automatically when needed.

**Weapons & NPCs:**
- Added circular bullets and smarter AutoGun targeting.
- NPC shooters now spawn with pooling and proper limits.
- Mana checks added to card triggers.

**UI & Debug:**
- Added a debug panel for quick in-game testing.
- Fixed some annoying errors and made event handling cleaner.

**Settings:**
- Centralized all board and color settings in a GameSettings singleton.
- Made a runtime settings panel so you can tweak board size/colors live.
- Board resizing is safe: it won’t shrink if cards are in the way.
